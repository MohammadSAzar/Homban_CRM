# Homban CRM

Homban is a Persian, mobile-first real estate CRM web application.

## Backend

- Python 3.10
- Django 5.2 LTS
- Django REST Framework
- MySQL with utf8mb4 is used for development and tests (test_homban_db).
- Production deployment remains future/incomplete.

## Architecture

Backend-first, REST API based architecture.

## Language

The application UI is Persian and RTL.
Source code and technical identifiers are written in English.
